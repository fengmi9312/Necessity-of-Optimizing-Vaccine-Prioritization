# Agent Working Rules

These rules apply to this repository and all automated agents working in it.

## Filesystem Access

- Files outside this project directory are read-only. Do not create, modify, move, or delete files outside the project.
- Inside this project, the following directories are read-only:
  - `AnalysisData/`
  - `AnalysisDataTmp/`
  - `ExperimentalData/`
  - `ExperimentalDataTmp/`
  - `Figure/`
- Do not create, modify, move, or delete files in those read-only directories.
- Files elsewhere inside the project may be edited when needed for the user's task.

## General Conduct

- Preserve user changes. Do not revert or overwrite files unless the user explicitly asks for it.
- Keep edits focused on the requested task.
- Prefer reading and understanding existing project structure before making changes.
